Rules I build by

What keeps an agent useful once it is in a live system.

  • A person approves every write that matters. Agents propose, people confirm.
  • Numbers come from code, words come from the model. Pricing, totals and dates are never left to a prompt.
  • Every output is checked by something that did not produce it: a second agent, a test set or a schema.
  • Evidence travels with each finding, so a reviewer can see why.
  • Sandbox records first. Nothing goes live without sign-off.
  • Costs and rate limits are measured before launch, not discovered after.
